# متن پیشنهادی معرفی محصول برای ژاکت

## عنوان محصول
قالب HTML لندینگ پیج Nova SaaS | دو زبانه فارسی و انگلیسی

## خلاصه کوتاه
قالب لندینگ پیج مدرن و واکنش‌گرا برای معرفی محصولات نرم‌افزاری و سرویس‌های SaaS، با طراحی روشن و آبی، پشتیبانی از زبان فارسی و انگلیسی و تغییر خودکار جهت RTL و LTR.

## توضیحات کامل
Nova SaaS یک قالب HTML مستقل برای معرفی محصولات نرم‌افزاری، سرویس‌های آنلاین و کسب‌وکارهای SaaS است. قالب با HTML، CSS و JavaScript خالص توسعه داده شده و برای اجرا به وردپرس، فریم‌ورک جاوااسکریپت، Node.js یا فرایند Build نیاز ندارد.

### امکانات
- طراحی مدرن، مینیمال و روشن با رنگ اصلی آبی
- پشتیبانی از دو زبان فارسی و انگلیسی
- تغییر جهت صفحه بین RTL و LTR
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- بخش معرفی اصلی محصول (Hero)
- پیش‌نمایش داشبورد با طراحی CSS
- بخش امکانات و راهکارها
- بخش پلن‌ها و قیمت‌گذاری نمونه
- پرسش‌های متداول
- بخش تماس با قابلیت تنظیم ایمیل
- منوی موبایل
- ذخیره زبان انتخاب‌شده در مرورگر
- مستندات راه‌اندازی، ویرایش و به‌روزرسانی

### فایل‌ها و فناوری‌ها
- HTML5
- CSS3
- JavaScript خالص (Vanilla JS)
- بدون نیاز به نصب افزونه یا کتابخانه خارجی

### نحوه نصب
پس از دریافت فایل ZIP، آن را از حالت فشرده خارج کنید و فایل `index.html` را در مرورگر باز کنید. برای انتشار آنلاین نیز محتویات پوشه قالب را روی هاست استاتیک یا هاست معمولی آپلود کنید.

### نکته مهم
این محصول یک قالب فرانت‌اند است و نرم‌افزار SaaS آماده یا پنل مدیریتی واقعی نیست. امکانات ورود کاربران، پرداخت آنلاین، اشتراک، پایگاه داده، تحلیل زنده و ارسال سمت سرور فرم تماس در آن پیاده‌سازی نشده‌اند. اطلاعات داشبورد و قیمت‌ها صرفاً نمونه هستند و باید متناسب با کسب‌وکار خریدار ویرایش شوند.
