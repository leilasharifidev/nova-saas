# Nova SaaS — Update Guide

This template has no package manager or build pipeline. Updates are made directly to the source files.

## Recommended update workflow
1. Keep a backup of your current customized folder.
2. Review the release notes supplied with any new version.
3. Compare changed files before replacing customized files.
4. Re-apply your own text, email, pricing, and branding changes if an updated file overwrites them.
5. Test the English and Persian versions, navigation, contact link, and responsive layouts.
6. Upload the updated folder to your hosting provider.

## Files commonly customized
- `index.html`: page content, section order, dashboard sample data, and links.
- `assets/css/style.css`: colors, typography, spacing, and responsive layout.
- `assets/js/app.js`: translations and interface behavior.
- `assets/js/config.js`: customer contact email.

There is no automatic updater. Updates must be applied manually.
