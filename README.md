# Nova SaaS | Bilingual Landing Page

A modern, responsive SaaS landing page featuring a clean visual identity, elegant blue accents, and seamless English and Persian language support.

Nova SaaS is an independent front-end project focused on modern web design, responsive layouts, and bilingual user experiences.

## Preview

![Nova SaaS Preview](preview.png)

## Features

- Modern and minimal UI design
- English and Persian language support
- Automatic RTL / LTR layout switching
- Fully responsive desktop, tablet, and mobile layouts
- Interactive language switcher with saved preferences
- Custom CSS-built dashboard preview
- Features, solutions, pricing, FAQ, and contact sections
- Responsive mobile navigation
- Accessible FAQ interactions
- Dynamic date and copyright year
- Lightweight implementation with vanilla JavaScript
- No frameworks or external runtime dependencies

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
